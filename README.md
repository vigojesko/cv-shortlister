# CV Shortlister — Google login & Netlify

Mulai dari **[MULAI-DI-SINI.md](MULAI-DI-SINI.md)** untuk pemasangan dan pengujian.

Paket ini menambahkan Google sign-in + Gmail consent, isolasi data per akun, PostgreSQL untuk data/file, serta Scheduled dan Background Functions Netlify. UI, prompt AI, dan formula skor dari branch `cv-latest-google-login` dipertahankan.

Ini source lengkap untuk di-build melalui GitHub → Netlify, bukan ZIP statis untuk Netlify Drop. Anda tetap perlu memasang secret, database online, dan callback Google di akun Anda sendiri.

Lihat [HASIL-PENGUJIAN.md](HASIL-PENGUJIAN.md) untuk hasil validasi dan keterbatasannya.
